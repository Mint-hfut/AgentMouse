# AgentMouse 代码审计与微信实测

本项目把智能体的截图、窗口识别和鼠标指令接到 Windows 或 Browser Bridge。检查按“一名 Windows 用户、一个活动控制智能体”进行；多智能体共享控制器是已声明的限制，本轮没有扩展为并发输入系统。

检查覆盖原生控制器/窗口与输入保护、WGC 生命周期、Core MCP、Full 适配层、浏览器引擎与扩展、安装/打包入口、技能和现有测试。深入追踪截图→观察编号→输入→核对→暂停/断连链路；安装/打包检查入口和现有回归，不逐行审查全部第三方依赖。以下包含对开发中改动的复核。

## 必须修复

1. **真实微信会主动置前，邮箱任务失败——未解决**（`Core.cs` 原生窗口消息通道）
   - 作用：向明确的后台窗口发送点击，随后检查前台、层级和鼠标位置。
   - 问题：重启微信后的实测中，点击发送到 `Qt51514QWindowIcon`，微信主动变成前台；目标“QQ邮箱提醒”会话没有打开。真实鼠标位置未变，不能因此把它记作无干扰后台成功。
   - 处理：控制器自动暂停，停止重复点击，常规微信隔离仍保留。需要验证另一条真正兼容的后台输入路径；本轮没有用全局鼠标、前台操作或 UIA 绕过失败。
   - 不处理的后果：继续宣传或放开普通微信后台操作，会抢用户前台且可能持续错误操作。原有持续卡死的具体根因仍未证明。

2. **截图卡住后，释放也排在卡住的线程后面——已修复**（[`WindowCapture.cs`](../../WindowCapture.cs)、[`Core.cs`](../../Core.cs)）
   - 作用：读取 HWND 的真实 WGC 图像并在暂停时结束捕获。
   - 问题：旧实现把截图和 Reset 放在同一个工作队列；截图线程卡住时，Reset 无法执行。截图返回后仍保留会话和 GPU 帧，黄色边框也可能持续存在。
   - 处理：每次截图在独立 CLI 进程中完成，释放帧/会话后才返回图像。父进程给出 4.5 秒上限，暂停可直接结束自己启动的截图进程；不存在排在截图后面的释放队列。停止失败必须报错。
   - 不处理的后果：工具超时不等于捕获停止，用户暂停后目标仍可能处于捕获状态。受控卡住/取消进程测试、真实 WGC/Qt 测试已通过；这不证明微信卡死根因已解决。

3. **新时间戳会放行内容未变的截图——已修复**（[`Core.cs`](../../Core.cs) `FrameAdvanced`）
   - 作用：阻止一次动作后继续使用没有进展的画面。
   - 问题：重新创建捕获会话可产生新的采样时间，图像像素却仍相同；仅比较时间戳会允许重复点击。
   - 处理：同时比较真实 PNG 的内容散列；同一进程的动作后画面必须具有更晚时间且内容不同。`frameChanged` 也改为比较内容，连续相同截图的回归测试已通过。
   - 不处理的后果：智能体可能把“又截了一次图”当成“应用已执行”，反复点击。内容变化仍只是允许重新判断，并非业务成功证明。

4. **启用与断连交错时可留下已启用控制器——已修复**（[`mcp-server.mjs`](../../mcp-server.mjs)、[`fusion-worker.mjs`](../../fusion-worker.mjs)）
   - 作用：按用户明确授权启用输入，并在控制会话断开后暂停。
   - 问题：新增显式启用如果不计入本会话活动，未发第一个点击就断连会遗留启用状态；断连暂停先执行、启用后返回也有同样风险。
   - 处理：显式启用计入会话活动；若它在断连后返回，再次暂停并返回会话已关闭。Core 和实际 Full worker 的延迟启用/EOF 测试均检查最终暂停。
   - 不处理的后果：会话结束后指针和输入许可可能继续保留。默认启动仍暂停；Full `pointer_open(allow_input=true)` / Core `pointer_open(allowInput=true)` 仅用于用户已明确授权的任务，且要求输入监测就绪、没有未释放接触、不启用触摸实验模式。

5. **Full 路径也必须拒绝旧控制器——已修复**（[`mcp-server.mjs`](../../mcp-server.mjs) `callApp`）
   - 作用：Core MCP 和 Full worker 共享原生 CLI 连接，但 Full 不经过 Core 的工具处理器。
   - 问题：只在 Core 工具处理器检查新截图能力，会让 Full 直接连接仍在运行的旧控制器并使用旧捕获实现。
   - 处理：共享原生入口也检查隔离、身份和旧帧保护；缺少时在截图前报升级要求。实际 CLI→命名管道回归证明只查询 status，没有发送 observe。
   - 不处理的后果：源码升级后 Full 仍可能复用旧控制器，导致修复未生效。

## 应修复

6. **失败的 UIA 查询仍可能提供可点击标签——已修复**（[`fusion/engine.py`](../../fusion/engine.py)、[`fusion/server.py`](../../fusion/server.py)）
   - 作用：把目标窗口的控件标签与当前截图绑定，并支持等待控件。
   - 问题：提供方失败时可能留下部分控件；旧路径仍可据此选标签，WaitFor 也可能反复查询或匹配失败结果中的节点。
   - 处理：错误/`providerSucceeded=false` 时丢弃全部标签；WaitFor 立即返回 `accessibility_unavailable`。纯逻辑和真实 MCP 的失败提供方测试已通过；微信 UIA 仍被禁止。
   - 不处理的后果：错误标签可能引导点击，重复查询也可能持续干扰不稳定的提供方。

7. **后台连接写入失败会遗留等待请求——已修复**（[`fusion/client.py`](../../fusion/client.py)）
   - 作用：管理 Python 到 Node worker 的异步请求与响应。
   - 问题：登记请求后的写入/等待排空原先不在 finally 覆盖内；断管时可能遗留 pending。已退出或读循环已停止的 worker 也不应继续接收新请求。
   - 处理：把写入放入清理范围、限制排空等待、清理 future，并对死 worker 快速报错；不自动重放结果未知的输入。断管与已退出 worker 测试已通过。
   - 不处理的后果：故障后请求积压，后续工具长时间等待，智能体可能误判为应用无响应。

8. **浏览器释放失败后却清空持有状态——已修复**（[`browser-extension/background.js`](../../browser-extension/background.js)）
   - 作用：释放浏览器按键并断开调试会话。
   - 问题：旧 `releaseAll` 无论释放、断开是否成功都清空状态；用户停止的响应也可能在失败后丢失。
   - 处理：只清除确认清理的会话；释放和断开都失败时保留状态、返回错误并停止输入。实际扩展清理代码的失败注入测试，以及真实扩展/Full 浏览器组件测试均通过。
   - 不处理的后果：工具可能报告结束，却丢失未确认释放的状态。强制终止所有相关进程仍不是已验证的释放路径。

9. **能发现托盘应用，却没有后台展开操作——已补齐并测试**（[`DesktopInventory.cs`](../../DesktopInventory.cs)、[`fusion/server.py`](../../fusion/server.py)）
   - 作用：从已运行进程发现窗口，再取得后台画面。
   - 问题：隐藏窗口不能截图，旧 Full 只有 list/find，工作流容易停住或另开一份应用。
   - 处理：Full `App(mode="show", window_id=...)` 只展开明确的既有隐藏窗口，放在底部并核对进程与前台。覆盖窗口测试通过；不支持最小化恢复，也不承诺目标应用不会自行改变窗口状态。
   - 不处理的后果：发现应用后仍无法进入后续观察，智能体容易错误重启应用。

## 验证与结果

- 通过：编译、主测试、原生状态/窗口路由、四种按键释放异常、Full SDK（26 工具）、9 个 Python 检查、Full 原生集成、Qt 真实按钮与连续截图检查。
- 通过：实际扩展清理失败注入、Core/Full 断连启用竞争、真实 Browser Bridge 和 Full 的浏览器组件测试。浏览器两次新测试是 headless 组件检查，不记作本轮桌面前台保持验收。
- 失败：真实微信→QQ 邮箱→读取第一封邮件。截图确实取得，点击确实发送，但微信主动置前且会话未切换，因此停止；没有读到邮件，没有发送聊天消息。
- 只读复核：微信主窗口 `enabled=true`、系统挂起启发式为 false、目标线程鼠标捕获为 0。这些指标不能证明用户实际交互正常，也不能排除微信自定义渲染故障。
- 截图、会话内容、账号信息未提交到仓库。[脱敏实测记录](../test-results/wechat-pilot-2026-11-04.json)。

结论：输入/截图生命周期和错误处理中的具体问题已修复并有回归，微信后台业务兼容性仍不合格。保持常规微信隔离，不发布为微信已修复版本。

未检查：全部上游/第三方源码、真实 CAPTCHA 服务、真实邮件业务后续步骤、本轮新安装包与五种客户端的更新后 UI。未执行私有聊天/邮件写入、UIA 微信查询或全局鼠标兜底。
